# Land Use Classification and Urban Heat Analysis

## Overview

This project analyzes land-use and land-cover (LULC) changes in Mumbai between 2000 and 2025 using Landsat satellite imagery and Google Earth Engine.

The study investigates the relationship between urbanization and land surface temperature (LST) and predicts future land-use trends for 2030.

## Technologies

- Google Earth Engine
- Python
- Google Colab
- Random Forest Classification
- Linear Regression
- Landsat Satellite Data

## Key Results
- 99.75% classification accuracy
- Positive correlation between urbanization and temperature
- 2030 land-use prediction using Linear Regression
